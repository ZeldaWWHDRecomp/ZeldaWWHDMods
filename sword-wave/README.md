# Sword Wave

At **full hearts**, a sword Spin Attack launches a forward-moving semicircular
wave. Quick spins, charged spins and the start of Hurricane Spin can fire it.
Ordinary slashes, charging alone and carried enemy weapons cannot.

## Install and settings

Install **Sword Wave** from the community catalogue, enable it and complete
code-mod setup if requested. Requires mod manager 1.6.0 or later; supports USA/EU.
**Enable Sword Wave** is the only option and can be changed during play.

## Behaviour and limits

- One active wave; another eligible spin replaces it.
- Uses native Spin Attack effects and sword damage, with a 2,400-unit range.
- Aims at the lock-on target or forwards without lock-on; consumes no magic.
- Stops at walls or a native shield block. Ordinary enemy hits do not stop it.
- Losing health after launch does not recall the wave.
- Pauses with gameplay; clears on death, cutscenes, stage/room changes, save
  loading or disabling the option.

Version **1.0.0**.

Enable **Show experimental mods** in the mod manager to find this mod.
