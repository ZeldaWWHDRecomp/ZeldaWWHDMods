# Combat icons

The four medallions were created for BeZide93 with OpenAI image generation.
The three attack icons were edited to replace the sword with a generic design
while retaining their illustrated medallion style. The dodge boot is unchanged.
They are distributed under MPL-2.0; see ASSETS.md and ../LICENSE.
Each 256×256 RGBA image uses 256 KiB of decoded texture memory (1 MiB total).

No Master Sword illustration or extracted game artwork is included.
